# Customer-Shopping-Behaviour-Analysis
End-to-end data analytics project studying 10,000 customer shopping records using Python (pandas), PostgreSQL/SQL, and Power BI to uncover purchasing patterns, customer segmentation, and revenue trends.
# Customer Shopping Behaviour Analysis

## Project Overview
This end-to-end data analytics project explores purchasing patterns, customer demographics, and revenue drivers across 10,000 retail transactions. Using **Python**, **PostgreSQL**, and **Power BI**, this analysis uncovers actionable business insights to improve customer retention, optimize discount strategies, and boost overall sales performance.

## Tools & Technologies
* **Python (Pandas, NumPy):** Data cleaning, exploratory data analysis (EDA), handling missing values, and feature engineering.
* **PostgreSQL:** Database management and answering key business questions through structured SQL queries.
* **Power BI:** Interactive dashboard creation to visualize KPIs, customer segments, and sales trends.

## Repository Structure
* `customer_shopping_analysis.ipynb` — Jupyter Notebook containing data preprocessing and exploratory analysis.
* `business_queries.sql` — SQL scripts solving key business questions (revenue by gender, subscription impact, top products, etc.).
* `customer_dashboard.pbix` — Interactive Power BI report file.
* `customer_data.csv` — Cleaned dataset used for analysis.
* `Project_Report.pdf` — Detailed documentation and presentation of findings.

## Key Business Insights
* **Customer Segmentation:** Categorized shoppers into *New*, *Returning*, and *Loyal* segments based on purchase frequency to tailor marketing campaigns.
* **Subscription Impact:** Evaluated average spend and total revenue differences between subscribed and non-subscribed customers.
* **Discount & Promo Performance:** Identified which product categories rely most heavily on discounts and how promo codes affect order volume.
* **Top Performing Categories & Items:** Highlighted highest-grossing product categories, seasonal trends, and top-rated items.

## How to Use This Project
1. **Clone or download** this repository to your local machine.
2. Open the `.ipynb` file in **Jupyter Notebook** or **VS Code** to review the Python data cleaning pipeline.
3. Import the `.csv` dataset into **PostgreSQL** and run the queries inside `business_queries.sql`.
4. Open `customer_dashboard.pbix` in **Power BI Desktop** to interact with the visualizations.
